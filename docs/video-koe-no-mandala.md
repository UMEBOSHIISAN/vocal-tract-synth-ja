# 声の曼荼羅

声道シミュレータ日本語版で、漢訳の般若心経を日本で用いられる読みで唱えました。独唱・三人・六人・十二人それぞれで全文を合成し、経文の句に合わせて編成を切り替えています。[完成動画（MP4・2分12秒）](../media/koe-no-mandala-hannya-1-3-6-12-X.mp4?raw=true)

| 時刻の目安 | 経文 | 声と舞台 |
|---|---|---|
| 0分00秒 | 摩訶般若波羅蜜多心経 | ひとりの声と光背 |
| 0分12秒 | 照見五蘊皆空 | 三人が三角に向き合う |
| 0分39秒 | 是故空中無色 | 六人が六角の輪をつくる |
| 1分11秒 | 菩提薩埵 | 十二人が円座で唱える |
| 1分55秒 | 故説般若波羅蜜多呪 | 独唱と三人の声に戻る |
| 2分01秒 | 羯諦羯諦 | 四つの音源と舞台が一斉に重なり、結びの「般若心経」まで続く |

経題から結びまで全276字。字幕の金色はそのとき読んでいる字を示します。映像は縦4:5（1080×1350、30 fps）、音声はステレオ。声道シミュレータ日本語版は、Jameson Hodge さんの「Chimera Vocal Synth」に着想を得ています。[原作リポジトリ](https://github.com/jamesondh/chimera-vocal-synth)
