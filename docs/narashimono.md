# 鳴らし物（法鼓・振鈴）— 出典と割り当て

2026-11-16 追加。般若心経の読経に、**実際の録音**（振鈴・法鼓）を重ねる機能です。録音5本を [audio/narashimono/](../audio/narashimono) に同梱しています。自分の録音に差し替えることもできます。

**資料に書いてあること**と**この版で決めたこと**を分けて書きます。宗派の正式な作法の再現ではありません。

## 使い方

1. 歌モードで「般若心経・全文（倍音ボイス）」を選ぶ。
2. 「同梱の録音を使う」を押す。ページをファイルから直接開いていて自動で読めないとき、または自分の録音を使うときは、「自分の音源を読み込む」でまとめて選ぶ。ファイル名に次の語が入っていれば自動で割り当てます（同梱の `shinrei`・`hokku-raimei`・`hokku-shutto`・`hokku-kak`・`hokku-don` も同じ仕組みです）。

   | ファイル名に含む語 | 役割 | 切り出し方 |
   |---|---|---|
   | 振鈴／しんれい | 冒頭の鈴 | いちばん鳴りの多いまとまり1つ |
   | 雷鳴／らいめい | 入堂の太鼓（短い） | いちばん鳴りの多いまとまり1つ |
   | 出頭／しゅっとう | 入堂の太鼓（通し） | 最初の音から最後の音まで |
   | カッ | 角打ち（打ち上げ） | 1打ずつ。順番に使い回す |
   | ドン | 読経の拍子・締めの一打 | 1打ずつ。順番に使い回す |

3. 読み込むと「鳴らし物：ON」になります。再生、または WAV 書き出し（ファイル名に `_narashi` が付きます）。

読み込んだ音源はこのブラウザの中（IndexedDB）に保存し、次に開いたとき戻します（鳴らし物は OFF のまま戻ります）。「保存した音源を消す」で消せます。5つ揃っていなくても、ある分だけ使います。

## 資料に無く、この版で決めたこと

- **振鈴→法鼓→読経を一続きにしたこと。** 「朝、振鈴で起き、法鼓で入堂し、朝課で読経する」という流れを縮めた演出です。実際には振鈴と朝課のあいだに時間があります。
- **打ち上げの打数と間。** 資料には「角打ちで盛り上げる」としかありません。7打・間を0.8倍ずつ詰める・最後にドン、はこの版の作りです。「七五三の割合」が何を数えるのかは資料に説明が無く、使っていません。
- **型打ち（ドン・ドドン・ドン、ドン…）は合成していません。** 単発の録音から型を組むと、譜の解釈を勝手に足すことになるためです。聴きたいときは出頭太鼓の録音を通しで流してください。
- **読経の拍子が法鼓であること。** 「大太鼓が般若心経の拍子を取る」という記述は宗派を限らない一般の説明です。禅宗の朝課で法鼓を1字1打で打つ、という資料は見つけていません。
- **音量の比。** 拍子は読経より小さく（録音のピークに対して 0.36×音量つまみ）、入堂と締めは大きくしています。既定の音量（つまみ 0.7）はオーナーが聴いて確認しました（2026-11-16）。
- **流儀の違い。** 花園禅塾ブログは「臨済宗では鳴らし物に関しては、本派で統一されていることがなく、本山流とか江湖流とか銘打って、打ち方が異なる」と書いています。ここでの並べ方はそのどれでもありません。

## 音の扱い

- 太鼓は1台とみなし、カッ・ドンは次の打で前の余韻を切ります（0.09秒で消す）。振鈴・雷鳴・出頭太鼓は切りません。
- 録音は残響を足さず、声と同じ出口（歪み止めの手前）に入れます。録音に元から入っている部屋の響きはそのままです。
- WAV は、書き出した読経に鳴らし物を足して描き直します。太鼓を足すぶん声を 0.85 倍にしています。
- 1打ずつの切り出しは、音量が急に 9dB 以上立ち上がる所を打点とし、次の打に食われて1秒に満たない打は、長い打が3つ以上あれば捨てます。

## 確かめたこと（2026-11-16）

- Node 試験 43件（うち鳴らし物 7件：ファイル名の割り当て、切り出し、字ごとの拍、並べ方、余韻を切る長さ）が通過。
- 「同梱の録音を使う」：http で開いたページでは5本とも自動で読み込み、ファイルから直接開いたページでは読めず案内文が出ることを Chrome（headless）で確認。
- 実際の録音5本を Chrome（headless）で読み込み：5本ともデコード成功。切り出しは 振鈴 8.0秒・雷鳴 10.6秒・出頭太鼓 206.7秒・カッ 6打・ドン 6打。
- 般若心経全文（12人・低音合唱）：拍 276（題10字＋本文262字＋結び4字）、入堂 18.2秒、打ち上げ 6.6秒。ライブ再生で 286 個の音が予約され、STOP で 0 個になること、OFF では従来と同じ長さになることを確認。
- WAV 書き出し：189.4秒・ステレオ。スペクトログラムで 振鈴→雷鳴→間→読経＋拍子→角打ち7打→ドン の順を目視。
- オーナーが Chrome で既定の設定を聴いて確認（2026-11-16）。読経経験者による確認はまだです。
- **まだ確かめていないこと：** 「通し」「2字1打」など既定以外の設定の聴感。Chrome 以外のブラウザ。管モデル・36人以上での組み合わせ。速度を変えたとき。

## 録音について

この機能を作るときに使った5本（振鈴、法鼓の雷鳴・出頭太鼓・カッ・ドン）は、オーナーの友人による生録音です（オーナー申告・2026-11-16）。市販や配布物の音源ではありません。オーナーの判断で、録音ファイルと、重ねて作った動画を同梱しています。このアプリの外で録音を使うときの条件は定めていないので、オーナーに問い合わせてください。

| ファイル | 中身（実測） |
|---|---|
| `shinrei.m4a` | 振鈴。単発2回と振り鳴らし（約2.2kHz）。28.9秒 |
| `hokku-raimei.m4a` | 法鼓の雷鳴。約10秒の連打と短い2回目。16.6秒 |
| `hokku-shutto.m4a` | 法鼓の出頭太鼓の通し演奏。3分33秒 |
| `hokku-kak.m4a` | 法鼓の縁打ち（カッ）の単発6回。32.3秒 |
| `hokku-don.m4a` | 法鼓の皮面打ち（ドン）の単発7回。43.8秒 |

自分で別の録音を重ねて公開するときは、その録音の利用条件を確かめてください。
