# 十二人の堂 — 12声を中心にした追加調整

現状はローカルの開発途中版です。従来のcheckpointは [verification.md](verification.md)、音響の出典・近似の境界は [sources.md](sources.md)。このページは後続の12人向け変更の記録であり、旧checkpointの測定を書き換えるものではありません。

## 起動

`index.html` を開き、SOUND LABの **「十二人の堂 — おすすめ」** → **PLAY**。
般若心経・12人・3Dへ切り替えますが、自動で音は出しません。エンジンの選択は保持します。管モデルも使えますが、対応ブラウザが必要です。小さな音量から確認してください。

## 変えたこと

- 同じ声を12回重ねず、既存の声道長・detune・定位の差に、個別の声源パルスの開放／閉鎖比の差を追加。
- 各人の音程・音量のゆらぎに、発音区間の長さの小さな違いを追加。隣接区間が短い場合は変動を縮め、元のスコア全長は維持。全員のテンポを勝手にずらし続ける方法ではありません。
- 主声とゆらぎ0は従来どおり。値は医学的な実測でなく、合成上の調整です。
- 12人までは各声の**実際に予約したスコア時刻**から口・発声／休止表示を決定。胸の動きはこの休止に追従する模式図で、肺気量の実測でも実際の呼吸音生成でもありません。
- 12人表示の距離・角度・光のにじみを調整し、導師／番号を表示。動きを抑える設定では飾りの揺れを止めます。
- 合唱のWAVをステレオにし、ライブと同じ左右定位を全員共通のroom busの前へ入れました。ソロはモノラルのままです。

## プリセットの設定値

pulse open 0.4／close 0.12、倍音4/6/10、重み1/0.7/0.45、mix 0.55、帯域幅目安40Hz、human 0.65、小堂8×10×4m、RT設定1.4秒、wet 0.22。これらは聴感受入済みの最良値ではありません。

追加の声のopen差は最大 `0.04 × human`、close差は元のcloseに対して最大 `0.35 × human`。発音境界の変位は `min(25ms, 前区間×0.16, 後区間×0.16) × human` の範囲で、先頭・末尾を固定しています。特定集団の測定値から推定した分布ではありません。

## 実行した検証

Node **24試験成功**。新しいタイミング、声色、個別timeline、プリセット、WAVの2ch interleave、offlineのpannerをRED→GREENで確認。既存のSTOP／ループ試験も保持しています。

native OfflineAudioContextで、各スコアの先頭8秒を切り出し、通常のsource fadeと合成残響末尾を含めて描画しました。44.1kHz。下表は16bit符号化・比較用音量調整**前**のFloat32 PCMです。

[元データと測定時のindex.htmlのSHA-256](ensemble12-measurements.json)。新しい2条件とも左右差のRMSが非ゼロで、ステレオが単なる同一波形の複製ではないことを確認。管モデルは12個のnative offline workletの生成を確認し、管モデル表示だけのfallbackとは分けています。

ライブも12声・12人分の描画・口の状態差・STOP後のSTANDBYを確認。管モデルでは12個の実workletが動き、最終analyserの取得窓が非ゼロかつfiniteであることを確認しました。スピーカーやマイクの録音ではありません。

## 比較音の扱い

比較用コピーは、旧12声（旧小堂preset・mono）と新しい12声（上記preset・stereo）の**全体体験の比較**。個々の変更だけを分離したablationではありません。

元WAVは無正規化。別の試聴用コピーだけ、全長・全chのRMSを0.08へ揃える一定gainを掛けています。外部のEQ・limiter・resampling・追加fadeは掛けていません。RMS合わせはLUFSや知覚的な音量合わせではありません。

自己検証（self-verified）。本人の聴感、長時間再生、全曲の末尾・全切替え、別ブラウザ・実スピーカーの受入は未完了。合成空間・3Dの身体が実寺院／生体を再現したという主張もしません。独立レビューは利用上限で結果を得られておらず、PASS扱いしていません。
