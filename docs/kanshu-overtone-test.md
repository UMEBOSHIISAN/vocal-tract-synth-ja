# テスト指示書：実測のつまみをブラウザで確かめる

`docs/kanshu-overtone-shijisho.md` の8手順を終えたあとに、ブラウザで変更を確かめる手順です。人がやっても、ブラウザを操作できる AI にやらせても同じ手順で進められます。

## 決まり

- 上から順にやります。各テストの「期待」と**一字でも違ったら不合格**です。そこで止めて、テストの番号と、実際に出た文字を報告します。
- **A〜E は画面の文字と数値で判定します。** 耳は使いません。AI がやる場合はここまでです。
- **F は人が耳で判定します。** AI は F を「合格」と報告しないでください。
- つまみは、動かしたあと**次に再生を始めたとき**に効きます。

## 準備

1. `index.html` をブラウザで開く（ファイルをそのまま開けば動きます。ビルドは要りません）。
2. 画面の「歌う」を押す。
3. 曲の一覧から「般若心経・全文（倍音ボイス）」を押す。
4. 「倍音ボイスの調整」という欄が出ることを確かめる。出なければ不合格（テスト0）。

この欄の下に「現在: …」で始まる1行があります。A〜C はこの行を見ます。

## A：既定値が変わっていない

何も動かさずに、「現在:」の行を見る。

期待：

```text
現在: f2bw=25 / f2g=4.2 / f1g=0.8 / f3g=0.35 / noise=0.2 / hop=0.008 / lpf=5200 / f0=43 / snap=1 / root=-0.1 / rise=0 / vibCents=0 / vibRate=5.5
```

あわせて、つまみが **13本** 並んでいること（もとの7本＋足した6本）。

## B：「実測の値」ボタン

「実測の値（1人・2026-11-16）」を押して、「現在:」の行を見る。

期待：

```text
現在: f2bw=95 / f2g=0.5 / f1g=1 / f3g=0.2 / noise=0.2 / hop=0.008 / lpf=5200 / f0=53 / snap=0 / root=-0.1 / rise=83 / vibCents=50 / vibRate=5.5
```

つまみの位置と右の数字も、この値に動いていること。

## C：「初期値に戻す」ボタン

「初期値に戻す」を押して、「現在:」の行を見る。

期待：A とまったく同じ行。

## D：譜面の中身（コンソールで確かめる）

Chrome などのふつうのブラウザで `index.html` を開き、開発者ツールのコンソールを開く（Mac の Chrome は Command+Option+J）。コンソールに次の1行を貼って実行する。これは値を読むだけで、何も変えません。コンソールを開けない環境では、D は飛ばして「未実施」と報告します。

```js
(function(){var s=buildSongScore(currentSong).filter(function(x){return x.type==="vowel"}),u={};s.forEach(function(x){u[Math.round(x.f[1])+"/"+Math.round(x.f[2])]=1});return [s[0].f0a.toFixed(1),s[s.length-1].f0a.toFixed(1),s.every(function(x){return x.f[1]%98===0}),Object.keys(u).sort().join(" ")].join(" | ")})()
```

出てくるのは「最初の母音の高さ | 最後の母音の高さ | F2 が全部 98 の倍数か | F2/F3 の組」です。次の4つの状態で実行します。

| 状態 | そこまでの操作 | 期待する出力 |
|---|---|---|
| D1 | 「初期値に戻す」を押した直後 | `98.0 \| 98.0 \| true \| 1176/2860 1372/2280 1764/2620 2254/3040 882/2740` |
| D2 | 「実測の値」を押した直後 | `174.6 \| 183.2 \| false \| 1175/2860 1360/2280 1770/2620 2240/3040 860/2740` |
| D3 | 「初期値に戻す」→「舌の根」を右端（1）へ | `98.0 \| 98.0 \| true \| 2254/2500` |
| D4 | D3 のあと「舌の根」を 0 へ | `98.0 \| 98.0 \| true \| 980/3500` |

（表の `\|` は、実際の出力ではただの `|` です。）

読み方：

- **D1：** 今までと同じ譜面です。高さは 98Hz のまま、F2 は倍音に合っています。
- **D2：** 高さが 174.6Hz から始まり、終わりに 183.2Hz まで上がります（83セント）。F2 は母音のままで、倍音に合わせていません。
- **D3・D4：** 母音が5つあっても、F2/F3 の組が1つだけになります。舌の根のつまみが、母音と切り離して F2 と F3 を決めています。

終わったら「初期値に戻す」を押す。

## E：再生して、エラーが出ない

1. 「実測の値」を押す。
2. 「▶ 発音する」を押して、3秒ほど鳴らす。
3. 止める。
4. コンソールに赤いエラーが出ていないこと。
5. 「初期値に戻す」を押す。

鳴っている間に、コンソールで次を実行してもかまいません（任意）。

```js
[N.vibG.gain.value.toFixed(0), N.vib.frequency.value]
```

期待：`["50", 5.5]`（鳴らし始めてすぐは 50 に届く途中の値が出ます）。

## F：耳で確かめる（人だけ）

それぞれ、冒頭を10秒ほど聞けば足ります。

| | 操作 | 聞こえるはずのこと |
|---|---|---|
| F1 | 「初期値に戻す」→ 再生 | **今までと同じ音。** 変更前と違って聞こえたら不合格 |
| F2 | 「実測の値」→ 再生 | 声が高くなる。笛のような倍音が消える。声がゆっくり揺れる |
| F3 | 「初期値に戻す」→ 再生 | F1 と同じ音に戻る |
| F4 | 「初期値に戻す」→「舌の根」を 0 → 再生。次に 1 → 再生 | 0 では低い倍音、1 では高い倍音。どちらも母音が変わっても倍音の高さが動かない |
| F5 | 「初期値に戻す」→「声の揺れの幅」だけ 50 → 再生 | 声の高さだけが揺れる。ほかは F1 と同じ |
| F6 | 「初期値に戻す」→「読むうちに上がる量」を 600 → 最後まで再生 | 終わりのほうが、始めより明らかに高い |

F2 の音が「読経らしいか」は、ここでは判定しません。確かめるのは、つまみが書いてあるとおりに効くことだけです。

## 報告の書き方

```text
A: 合格／不合格（実際の行）
B: 合格／不合格（実際の行）
C: 合格／不合格
D1〜D4: それぞれ合格／不合格（実際の出力）
E: 合格／不合格（エラーの文）
F1〜F6: 人が聞いた結果。AI がやった場合は「未実施」
```

## この期待値の出どころ

A〜E の期待値は、2026-11-16 に、指示書の8手順を当てたコピーをブラウザで実際に動かして出た値です（コミット `d04ed3b` の `index.html` がもと）。同じ日に、同じコピーで、読経の経験者（薬樹ギン）が A・B・C と F1〜F6 を確かめ、すべて合格でした。確かめたのは「つまみが書いてあるとおりに効くこと」で、実測の値の音が読経らしいかどうかではありません。
