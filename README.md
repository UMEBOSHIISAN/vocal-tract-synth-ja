# 声道シミュレーター / Vocal Tract Simulator

**[English](README.en.md)** · [出典・モデルの限界](docs/sources.md) · [検証範囲](docs/release-readiness.md) · [第三者表記](THIRD_PARTY_NOTICES.md)

声をつくる仕組みを、音と動く声道で試すブラウザ実験室です。**日本語／Englishをその場で切替**できます。発音内容は日本語の仮名・母音・歌であり、英語表示は自然な英語TTSを追加するものではありません。

- 単一の `index.html`。ビルド、npm、APIキー、アカウント、音声サンプル、マイクは不要。
- 初回表示に外部フォント・CDN・解析通信を使いません。出典リンクを押した場合は外部サイトへ移動します。
- フォルマント合成と実験的な管モデル、手動調音、倍音ミキサー、合唱、合成残響、2D／3D表示、WAV生成。
- **教育・実験用の近似モデル**です。医療・診断、生体の完全再現、実在する声・僧侶・寺院の再現を保証しません。

## 最初の1分

1. `index.html` をブラウザで開きます。ローカルファイルで管モデルが使えないブラウザでは、下のlocalhost手順を使ってください。
2. **端末の音量を下げてから**「発音する」。STOPで音と残響を止められます。音は自動再生しませんが、母音・モーラ・単語・早口言葉のボタンも再生操作です。
3. 「歌う」→「十二人の堂 — おすすめ」→「▶ 発音する」で合唱へ。「導師」「2〜12」で一人を試聴し、「全員」で戻します。
4. 右上の**日本語／English**で表示だけを切り替えます。入力・曲・設定・再生を言語切替のためにリセットしません。`?lang=ja` / `?lang=en` でも選択でき、指定がなければ保存した選択、最後に日本語を使います。保存機能が拒否されても動きます。

### localhostで開く（推奨する検証経路）

このフォルダで次を実行し、`http://127.0.0.1:8000/` を開きます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Pythonは閲覧用の任意のローカルサーバーとして使うだけです。アプリのビルド工程ではありません。管モデルにはAudioWorkletに対応したブラウザと、HTTPSまたはlocalhost等の対応する安全なコンテキストが必要です。起動できない場合は表示のエラーを確認し、共鳴3本方式へ戻してください。選択した管モデルを黙って別方式に置き換えません。

## 操作

| モード・設定 | 内容 |
|---|---|
| なまむぎ | モーラ・単語・母音ごとの発音。表示の仮名は英語UIでも保持します。 |
| 自由入力 | ひらがな・カタカナ。対応しない漢字や英語は読み飛ばしとして表示します。読み飛ばした入力は翻訳せず、そのまま確認できます。 |
| 歌う | ふるさと、スキャット／音階練習、Twinkle、Made of air、般若心経。 |
| 手動調音 | 舌・顎・唇等を動かし、「声を出す」で確認。管モデルの準備中もSTOPで取消できます。 |
| 話者・VTL・デュエット | 共通モデルの設定。個人の実測解剖を再現するものではありません。 |
| 合唱・3D | 最大108人の図形を表示しますが、音響合成はデュエット込みで最大12系統です。人数・方式・品質設定の変更は再生開始そのものではありません。 |
| 低音合唱 | 般若心経の合唱に低音・五度・オクターブを加える芸術的な合成。従来の同音読誦にも戻せます。宗派の正式な唱法の実証ではありません。 |
| SOUND LAB | 声源、追加倍音、個別ゆらぎ、合成空間。実測IR・HRTF・絶対音圧は使っていません。 |

波形は合成出力の**相対値**、気流・人体・呼吸は模式的な表示です。フォルマントと3D断面積は同一のMRI実測モデルではありません。細かい出典と、本文／要旨／未照合の区別は[詳細ノート](docs/model-notes.ja.md)にあります。

## WAVを書き出す

「WAV 書き出し」は現在のフレーズ・曲・手動ポーズを44.1kHz／16bit PCMで生成します。追加合唱声がある場合はステレオ、それ以外はモノラルです。**一人だけの試聴選択はWAVへ入りません**。

- 単体と一括は同時に実行できません。一括の途中で失敗したらそこで止まり、生成・保存要求できた件数を表示して操作を戻します。
- 「保存要求」はブラウザへのダウンロード要求であり、アプリがディスクへの保存成功を読み取ったという意味ではありません。保存先を確認してください。複数ダウンロード許可が必要なブラウザもあります。
- 長い曲・管モデル・合唱はCPUとメモリを使います。まず短いソロで確認し、一括生成中は設定を変更せず待ってください。STOPはライブ再生の停止であり、進行中のオフライン生成を取り消すボタンではありません。
