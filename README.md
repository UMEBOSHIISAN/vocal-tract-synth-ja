# 声道シミュレータ日本語版 (vocal-tract-synth-ja)

ブラウザで動く、日本語向けの声道シミュレータです。単一の `index.html` だけで完結し、ビルド工程はありません(Google Fonts のみ外部から読み込みます)。フォルマント合成で母音・歌を鳴らします。

## 使い方

`index.html` をブラウザで開くだけです。

## 十二人の堂：一人ずつ聴いて遊ぶ

「十二人の堂」→ PLAY → **導師／2〜12** で一人を聴き、**全員**で合唱へ戻せます。選んだ人を明るく表示。WAVは試聴選択に関係なく全員です。遅い声まで待つ自然終了と、タブ非表示時の終了も修正しました。**[34試験・両方式の全文描画・数値一致の未達点](docs/polish12.md)** を参照。今回の後続版はローカル開発版です。

## 十二人の堂（12人向け追加調整）

SOUND LABの **「十二人の堂 — おすすめ」→ PLAY** で、12人の般若心経と3D表示へ。声色・発音タイミング・口と息継ぎ表示を個別化し、合唱WAVをステレオにしました。自動再生はしません。**[変更と24試験・native 12声の確認記録](docs/ensemble12.md)** を参照。聴感・全曲の受入はまだです。

## 般若心経（倍音ボイス）

歌モードの「般若心経・全文（倍音ボイス）」は、経題から本文、真言、締めの「般若心経」までを低い基音（G2・約98Hz）で唱えます。声道共鳴 F2 を基音の整数倍へ寄せ、帯域幅を狭めて倍音を浮かび上がらせます。調整は計測タブと歌モードのつまみで確認できます。

### 経文・読みの出典

- 本文は玄奘訳系の漢文を日本の伝承の読みで唱える形です。採用した経題、ふりがな、真言の表記は [曹洞宗・貞昌院版の経本](https://teishoin.net/blog/kyoten.pdf) を参照し、[大正蔵 T0251（CBETA電子版）](https://dlbs.liberal.ntu.edu.tw/BDLM/sutra/html/T08/T08n0251.htm) と本文・真言の異同を確認しました。息継ぎは句のまとまりに沿った合成用の区切りです。
- 真言はサンスクリット語の音を漢字で写した部分です。音は日本の読誦形で合成し、画面に [梵本のIAST表記](https://gretil.sub.uni-goettingen.de/gretil/1_sanskr/4_rellit/buddh/prajnhsu.htm) の対応する真言部分を併記します。[東京国立博物館の法隆寺献納宝物](https://emuseum.nich.go.jp/detail?content_base_id=100625&langId=ja) には梵字の心経写本があります。
- 合成音のテンポは [曹洞宗東海管区の公開読誦例](https://soto-tokai.net/ok_han.html) の録音長（約2分45秒）を参考に、標準で1字0.58秒と句間の息継ぎを設定しています。

### 倍音ボイスの根拠（文献）

- 倍音唱法では、F2（と F3）を強調する倍音の近くに寄せる。Adachi & Yamada (1999, ATR 技術報告 TR-H-0265) は、MRI から作った声道形状の F2 が目標の旋律音に 36 セント以内で一致したと報告している。Sundberg, Lindblom & Hefele (2021, *Logopedics Phoniatrics Vocology*) は、F2 と F3 の両方を同じ倍音の近くに寄せる「二重フォルマント」を報告している。**確認の範囲：** どちらも検索結果の要旨レベルまでで、全文は読んでいません。
- 従来の倍音ボイスは F2 の1本を倍音に吸着させる簡略化です（F3 は母音のまま）。F2 は共鳴器2本を交互に使って倍音間をホップします。SOUND LABの最大3本の追加帯域は別の人工的スペクトル処理で、生体の二重フォルマントそのものではありません。
- **未確認：** 日本の僧侶の読経・声明の F0 や帯域幅を測った文献は見つかっていません（一次文献の探索は途中）。F0=98Hz・帯域幅は近似値です。
- 日本語母音の声道断面積関数（Takemoto・Honda ら、ATR MRI データベース）の存在は確認しましたが、数値の取り込みはしていません。

### 発声と調音

撥音「ん」は鼻腔共鳴、促音「っ」は短い閉鎖、長音は同じ母音の持続として扱います。「ぎょう」「くう」のような表記も、調音では母音を伸ばします。子音ごとに調音の構えと音の立ち上がりを作り、低い声源と倍音の母音をつなぎます。子音の強さと時間配分は聴き分けのための近似です。促音の閉鎖を延ばす根拠は [日本語の促音の知覚研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4263088/) を参照しました。

## 3D ワイヤーフレーム

「立体 3D WIREFRAME」タブで、頭・咽頭壁・口蓋・顎・舌・軟口蓋・唇・声道の管を3/4ビューと側面ビューで表示します（ドラッグで回転）。既存の正中矢状断面の形を立体に起こした**近似**です。声道の管の断面は、中心線から壁までの矢状径を測り、左右幅を矢状径の1.35倍と仮定した楕円で描いています。MRI 実測の断面積ではなく、音の計算（フォルマント）にも使っていません。

表示している要素: 頭の輪郭・咽頭後壁・硬口蓋・歯列（上は固定、下は顎に追従）・顎・舌（面を半透明で塗り、輪切りで体積を表現）・軟口蓋・唇・鼻腔・舌骨・甲状軟骨・喉頭蓋・声帯・気管の輪・声道の管（断面を半透明の面でつなぎ、狭い部分ほど橙に着色）・声門から唇へ流れる気流の点・部位名ラベル（側面ビュー）・画面下の**断面積関数（推定）**グラフ（声門→唇、最狭部を橙で表示）。舌骨・喉頭蓋・甲状軟骨・気管の位置と大きさは解剖図を参考にした手置きの近似で、日本人の計測値ではありません。気流の点と断面積グラフも表示用で、音の計算には使っていません。

**動きと胸（2026-11-10 追加）:** 左ビューは胸まで引いた全体図、右ビューは声道の拡大です。

- 胸：肋骨・背骨・胸骨・肺・横隔膜・気管〜気管支を描きます。声を出すあいだ肺の空気が減って横隔膜が上がり、息継ぎで横隔膜が下がって腹が前へ出ます（腹式呼吸の模式図）。形・大きさ・動きの量は**実測ではない模式図**で、音の計算には使っていません。
- 声帯：前側（前交連）でつながり後ろ側が開く形で、発声中は細かく開閉、声が止まると開きます。開閉の速さは見えるように遅くした表示で、実際の振動数ではありません。
- 唇から広がる波面、舌の動きの残像、遠い線ほど淡くする奥行き表現、触っていない間のゆっくりした首振りは表示上の演出です。
- 右下の「いま鳴っている音の成分（実測）」は、出力を実際に周波数分析した値です。F1〜F3 の目標位置を縦線で示し、般若心経では狙っている倍音（第 k 倍音）に印を付けます。
- 般若心経では、読んでいる句を漢字とふりがなで表示し、読んでいる字を金色にします。
- 頭：網目を細かくし（縦の線 8 本・横の輪を密に）、眼窩・目・鼻翼・耳を足しました。頸椎は C1〜C7 を椎体の輪・棘突起・横突起で描きます。位置と大きさは解剖図を参考にした**手置きの近似**で、実測値ではありません。
- 線のにじみ（発光）は、描いた線画をぼかして重ねる表示上の演出です。

般若心経（倍音ボイス）を選んでいるときは**読経モード**になり、剃髪の頭に閉じた目・眉・鼻・耳・首・肩・衣の襟・袈裟の帯・数珠を線で足して僧侶の姿にします（演出のみ。音には無関係）。

## 合唱と曼荼羅

歌モードの「人数（合唱）」で 1・3・6・12・36・72・108人を選びます。人数は次の再生と単体WAV書き出しに反映されます。

- 3Dタブの左は曼荼羅、右は声道の拡大です。36人からは全員が中心を向く3重の輪になり、108人では内側18・中ほど36・外側54人です。各人に共通の口の動きを投影します。中心の蓮と、発声中に中心へ広がる光の輪は表示上の演出です。
- 12人までの曼荼羅では、各人を正座で合掌する全身の骨格として描きます（背骨＝頸椎7・胸椎12・腰椎5・仙骨、肋骨12対と胸骨・肋骨弓、鎖骨・肩甲骨、腕と手、骨盤、脚、肺・心臓・横隔膜、体表の輪郭）。縮尺は 10px≒1cm で、骨の長さ・胸郭の幅・背骨の弯曲は解剖学の標準的な比率を参考にした**手置きの近似**です（個人の実測値ではありません）。呼吸で肋骨が広がり横隔膜が上下する動きは表示上の演出です。
- 骨格の配置で確認した点：横隔膜は吸うと下がり声を出すあいだ上がる／正座は膝とすねが床につき、かかとが坐骨の下に来る／胸骨は第2〜3胸椎から第9胸椎の高さで、第1〜7肋骨は肋軟骨で胸骨へ、第8〜10は肋骨弓へつながる／心臓は左寄りで、左肺はそのぶん小さい。まだ合っていない点：頭の形は元の断面図を回したもの、顔の骨（下顎・歯）や筋肉・皮膚の面・静脈・腸などは無い。
- 曼荼羅の光の演出（星、中心の光と光の柱、立ちのぼる光の粒、頭の後ろの光背、口から中心へ向かう声の光、床の外周を回る経文の輪）は表示だけで、音の計算とは無関係です。経文の輪は、いま読んでいる字を金色で示します。
- 手足と胴には、骨に沿った筒と断面の輪で肉づきの輪郭を足しています（太さは手置きの近似）。輪の表示では頸椎の全長を約13cmにし、人ごとに呼吸のタイミングを少しずらします。床には蓮弁16枚・四方の門・炎の輪を足しました。中心近くの**倍音の星**は、いま F2 が合わせている倍音の次数（F2÷声の高さ）と同じ数の頂点を持ち、読む母音が変わると形が変わります。
- **人数が少ないほど1人を細かく描きます**（使える描画量が増えるため）。
  - 12人：骨格・肺・心臓・横隔膜まで（頭の網目は間引き）
  - 6人：＋椎骨の横突起、肋骨の厚み、気管支（右は太く短く急、左は長く水平ぎみ）、肺の葉間裂（右3葉・左2葉）
  - 3人：＋大動脈（弓は左後ろへ回り、脊柱の左前を下って第4腰椎の高さで分岐）と頸動脈、肝臓（右上腹部）、胃（左上腹部）
  - 1人（般若心経の独唱）：＋脳（大脳・小脳・脳幹）、脊髄（第1〜2腰椎の高さまで、その下は馬尾）、腎臓（右がやや低い）、細かい体表の輪、気道を上がる息の粒。本人が中心に座る全身表示になります。
  - 臓器の位置と形は標準的な配置を参考にした手置きの模式図で、実測ではありません。心拍（毎分約66回）と息の粒は表示上の演出です。
- 合成声はデュエットも含めて最大12系統です。声道長、音程、入りの時間と左右の定位をずらして重ね、読経では先導の声を前に出します。大人数時は軽い輪郭で描き、グループの声で合唱全体を表現します。ばらつきは演出用の値です。
- 再生中に3Dの経文とふりがなの読み位置が移り、真言の場面では梵文表記も出ます。WAVは44.1kHz・16bitで、ソロはモノラル、合唱（追加声あり）はステレオです。

## 管モデル（実験・2026-11-10 追加）

再生ボタンの並びにある「音の作り方」ボタンで、従来の**共鳴3本方式**と**管モデル**を切り替えられます（次の再生・WAV 書き出しから反映。既定は共鳴3本方式のまま）。

- 仕組み：声門から唇までの声道を、同じ長さの短い管をつないだ1本の音響管とみなし、管の中を往復する圧力波を1標本ずつ計算します（Kelly–Lochbaum 型の進行波モデル）。隣り合う管の断面積の比で反射が決まり、共鳴は結果として現れます。
- 断面積：5母音などの目標フォルマント（日本語の実測平均寄せの値）に共鳴が一致するよう、一様な管からのずれをコサイン3成分で逆算した**相対値**です（摂動理論：Schroeder 1967／Mermelstein 1967）。**MRI 実測の断面積ではなく**、3D タブの形とも別物です。
- 計測（2026-11-10時点の引き継ぎ記録）：逆算した管の共鳴と目標の差は最大 0.2%。5母音を鳴らした出力でも、目標に最も近い倍音に山が出ることを確認した、と記録されています。新しいSOUND LABの全経路の検証としては扱いません。
- 近似：声門流の波形（Rosenberg 型。割合は一次文献と未照合）、反射係数と損失（帯域幅を決める値。実測ではない）、唇の放射（1階差分）。
- 未実装：鼻腔への分岐（鼻音は口の管の形だけで近似）、摩擦・破裂の雑音の管内生成（従来どおり管の外で足します）。従来の倍音ボイスのF2帯域幅つまみは管自身の帯域幅には効きません。SOUND LABの追加帯域は管の出力後へ掛ける別処理です。
- **聴感は未確認です。** 新しいSOUND LABのnative計測はmanual/formantの4条件までで、新しい管モデル・合唱・空間の統合受入は未完了です。配線テストと実出力の確認範囲は [検証記録](docs/verification.md) に分けています。

## 出典一覧

このプロジェクトで使った資料を、**どこまで確認したか**と合わせてまとめます。確認の度合いは次の4段階です。

- **本文確認**：資料の本文を実際に読んで、該当箇所を確かめたもの
- **要旨まで**：検索結果や要旨の範囲で内容を把握したもの（全文は未読）
- **未照合**：著者・年・内容を一般に知られた形で記しているが、一次文献そのものとは突き合わせていないもの
- **出典なし**：資料に基づかず、手で置いた値や形
