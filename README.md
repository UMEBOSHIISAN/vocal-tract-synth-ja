# 声道シミュレータ日本語版 (vocal-tract-synth-ja)

ブラウザで動く、日本語向けの声道シミュレータです。単一の `index.html` だけで完結し、ビルド工程はありません(Google Fonts のみ外部から読み込みます)。フォルマント合成で母音・歌を鳴らします。

## 使い方

`index.html` をブラウザで開くだけです。

## 般若心経（倍音ボイス）

歌モードの「般若心経（倍音ボイス）」は、般若心経の冒頭（観自在菩薩〜空即是色）を低い一定音（G2・約98Hz）で読経します。母音ごとに声道共鳴 F2/F3 を最も近い高調波（F0の整数倍）に合わせ、帯域幅を狭めて、その倍音を浮かび上がらせる倍音唱法の近似です。パラメータは `ANAT.overtone` に集約し、根拠と近似の旨は「計測」タブに表示します。

- 原理は確立した音響理論（共鳴と高調波の一致）に基づきます。
- 日本の僧侶の読経のF0・帯域幅の公表データは用意できていないため、F0は成人男性の下端付近の近似、帯域幅は理論条件からの近似値です。
- 聴感は未確認です(ヘッドレスで描画し、各母音でF2目標の倍音が最大になることだけ確認)。

### 倍音ボイスの根拠（文献）

- 倍音唱法では、F2（と F3）を強調する倍音の近くに寄せる。Adachi & Yamada (1999, ATR 技術報告 TR-H-0265) は、MRI から作った声道形状の F2 が目標の旋律音に 36 セント以内で一致したと報告している。Sundberg, Lindblom & Hefele (2021, *Logopedics Phoniatrics Vocology*) は、F2 と F3 の両方を同じ倍音の近くに寄せる「二重フォルマント」を報告している。**確認の範囲：** どちらも検索結果の要旨レベルまでで、全文は読んでいません。
- 本実装は F2 の1本を倍音に吸着させる簡略化です（F3 は母音のまま）。F2 は共鳴器2本を交互に使って倍音間をホップします。
- **未確認：** 日本の僧侶の読経・声明の F0 や帯域幅を測った文献は見つかっていません（一次文献の探索は途中）。F0=98Hz・帯域幅は近似値です。
- 日本語母音の声道断面積関数（Takemoto・Honda ら、ATR MRI データベース）の存在は確認しましたが、数値の取り込みはしていません。

### 発声（読経の作法）

読経経験者の助言「声帯は途切れさせず、口腔内の変化で響かせる。腹式で圧を一定に保つ」に合わせ、般若心経（倍音ボイス）では子音の破裂・摩擦の雑音を鳴らしません。声を出したまま子音の構えへ短く滑り（「かんじーざいぼーさーぎょうじん」が「あーんいーあいおーあーおういん」のように聞こえる形）、鼻音は声を出したままの鼻腔共鳴にし、声源の強さは全区間で同じ値に固定しています。息継ぎは句の切れ目だけです。文献値ではなく経験者の助言に基づく近似です。倍音の聞こえ方は 2026-11-10 にオーナーが確認済み（「倍音感は最高に良くなった」）。

## 3D ワイヤーフレーム

「立体 3D WIREFRAME」タブで、頭・咽頭壁・口蓋・顎・舌・軟口蓋・唇・声道の管を3/4ビューと側面ビューで表示します（ドラッグで回転）。既存の正中矢状断面の形を立体に起こした**近似**です。声道の管の断面は、中心線から壁までの矢状径を測り、左右幅を矢状径の1.35倍と仮定した楕円で描いています。MRI 実測の断面積ではなく、音の計算（フォルマント）にも使っていません。

表示している要素: 頭の輪郭・咽頭後壁・硬口蓋・歯列（上は固定、下は顎に追従）・顎・舌（面を半透明で塗り、輪切りで体積を表現）・軟口蓋・唇・鼻腔・舌骨・甲状軟骨・喉頭蓋・声帯・気管の輪・声道の管（断面を半透明の面でつなぎ、狭い部分ほど橙に着色）・声門から唇へ流れる気流の点・部位名ラベル（側面ビュー）・画面下の**断面積関数（推定）**グラフ（声門→唇、最狭部を橙で表示）。舌骨・喉頭蓋・甲状軟骨・気管の位置と大きさは解剖図を参考にした手置きの近似で、日本人の計測値ではありません。気流の点と断面積グラフも表示用で、音の計算には使っていません。

般若心経（倍音ボイス）を選んでいるときは**読経モード**になり、剃髪の頭に閉じた目・眉・鼻・耳・首・肩・衣の襟・袈裟の帯・数珠を線で足して僧侶の姿にします（演出のみ。音には無関係）。
